# Skin Disease Prediction AI

An AI-powered web application for skin disease prediction using deep learning.

## Features
- User authentication (signup/login)
- Image upload and analysis
- Real-time skin disease prediction
- Confidence scoring

## Deployment
This app is designed to run on Streamlit Community Cloud.

### Local Development
1. Install dependencies: `pip install -r requirements.txt`
2. Run the app: `streamlit run streamlit_app.py`

### Online Deployment
1. Push to GitHub repository
2. Go to [Streamlit Community Cloud](https://streamlit.io/cloud)
3. Connect your repository
4. Set `streamlit_app.py` as the main file
5. Deploy!

## Usage
1. Create an account or login
2. Upload a skin image
3. Get AI prediction results
4. Consult with a dermatologist for medical advice

**⚠️ Disclaimer: This is for educational purposes only. Always consult healthcare professionals for medical decisions.**
